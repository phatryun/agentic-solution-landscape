# Orchestration

Orchestration frameworks provide the backbone for building multi-step, multi-agent AI systems.
They handle routing, state management, tool calling, and agent coordination.

## Key capabilities
- Chain / graph execution
- Agent memory management
- Tool / function calling
- Multi-agent communication
