# LangChain

LangChain is the most widely adopted framework for building LLM-based applications.
It provides abstractions for chains, agents, tools, and memory.

## Use cases
- RAG pipelines
- Conversational agents
- Document processing
- Tool-augmented LLMs

## Strengths
- Massive ecosystem and community
- Available in Python and JavaScript
- Deep integrations with vector stores, LLMs, and tools
